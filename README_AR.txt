منصة العراق التعليمية — ملف التحديث

المحتويات:
- index.html: ملف المنصة بعد إضافة الميزات.

طريقة التجربة:
1) افتح index.html في المتصفح للتجربة المحلية.
2) للنشر، استبدل ملف index.html في مستودع GitHub الخاص بالواجهة ثم انتظر اكتمال نشر Render.
3) الميزات التي تستخدم localStorage محفوظة على نفس المتصفح/الجهاز فقط.

ملاحظات مهمة:
- إشعارات المحاضرات والامتحانات والإعلانات وعلامة اللون الأحمر تعمل محلياً في هذه النسخة؛ إرسال إشعار إلى جميع أجهزة الطلاب يحتاج إضافة/ضبط مسارات الإشعارات في الخادم وقاعدة بيانات مشتركة.
- إحصائيات وقت الاستخدام تُجمع محلياً أثناء بقاء صفحة المنصة مفتوحة. ليست مدة مشاهدة فيديو مؤكدة، ولا يمكن جمع نتائج جميع الطلاب أو ترتيب مسابقة حقيقي دون ربط الخادم ومشغّل المحاضرة.
- قسم التحفيز يولّد نصائح مكتوبة محلياً ولا يحتاج مفتاح API؛ هذا ليس استدعاءً لنموذج ذكاء اصطناعي خارجي. ربط ذكاء اصطناعي فعلي يحتاج endpoint على الخادم ومفتاح API محفوظ في إعدادات الخادم وليس في HTML.
- تغيير الاسم والألوان والشعار/الأيقونات يعمل محلياً على الجهاز الحالي. نشر التغييرات لجميع الطلاب يحتاج تخزين الإعدادات على الخادم.
- لا تضع مفتاح إدارة أو مفتاح API سري داخل ملف HTML منشور.
